Four tools on one local page

Each one does a single job, and each one works without a network connection.

Non-destructive freezing

Pause a memory-hungry app and it stops using the processor at once. Its memory, open files and unsaved work stay exactly as they were. Resume it and it carries on from the same instruction.

proc.suspend() · proc.resume()

Shortest-job-first automation

Queue your heavy tasks and ThrottlerOS runs them one at a time, shortest estimate first. Quick jobs finish early instead of waiting behind a long export.

queue.sort(key=lambda j: j.est_seconds)

Dual-column segregation

Apps you launched sit on the left. Windows services and system background tasks sit on the right. Protected system processes are listed but locked, so you cannot freeze one by accident.

scope = "external" | "system"

Complete local privacy

The interface is served from 127.0.0.1:8000 and nowhere else. There are no accounts, no usage reports and no update checks. Unplug the network cable and it behaves the same.

uvicorn.run(app, host="127.0.0.1", port=8000)

About

Why a PC slows down when nothing looks wrong

Every runnable thread waits for a slice of processor time. When a browser, an indexer, a sync client and an update service are all runnable at once, the scheduler rotates between them. Each rotation costs a context switch and leaves the CPU cache cold. Your foreground app gets a smaller share, delivered in smaller and less predictable pieces. That is thread contention.

What suspension does

ThrottlerOS suspends a process through the same kernel mechanism debuggers use (NtSuspendProcess on Windows, SIGSTOP on POSIX/Linux/macOS). The process's threads stop being scheduled. Its memory, open files and handles stay as they were, so no work is lost and nothing has to restart. When you resume it, every thread continues from the instruction where it stopped.

What it does not do

A suspended process still owns its memory. Freezing returns processor time, disk activity and memory bandwidth immediately, and it lets the OS trim the idle working set if memory gets tight. It does not give RAM back on the spot. If you need the memory itself, close the application.

Why shortest job first

When several heavy tasks are waiting, running them one at a time in order of estimated runtime gives the lowest average wait. The scheduler holds the long job back until the short ones are done, so they stop competing for the same cores.

Help

Connect & Troubleshoot

ThrottlerOS runs locally on this machine and can be accessed from other devices on your home or office network:

http://127.0.0.1:8000
http://192.168.1.x:8000

📱 Connect from your phone or tablet on the same Wi-Fi using the LAN address above.

How do I start and stop SYSmin?

Windows: Double-click run.vbs to start. Double-click run.vbs again and click NO to stop.

Linux & macOS: Run ./run.sh to start, and ./run.sh stop to cleanly exit.

How do I monitor and throttle from my phone or tablet?

Start the server with the --lan flag:

python -m backend.main --lan --port 8000

The backend binds to 0.0.0.0 and outputs your machine's LAN address (e.g. http://192.168.1.15:8000). Open that URL in your mobile browser to control processes remotely!

I get AccessDenied when I freeze a process

That is psutil.AccessDenied. Run terminal as Administrator (Windows) or root/sudo (Linux). Protected system services (System, csrss.exe, systemd, etc.) are permanently locked by design.

Is it safe to freeze a browser or game?

Yes. When resumed, the application continues from its exact instruction state with unsaved documents and tabs intact.
